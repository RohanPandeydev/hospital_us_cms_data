🔀 Unified Device Code Crosswalk

One searchable index that connects every identifier type we've ingested: CMS billing codes (HCPCS), inpatient DRGs, FDA product codes, 510(k) K-numbers, Unique Device Identifiers (UDI-DI), brand names, manufacturers, and GMDN preferred terms — all mapped to the same device-category vocabulary.

Why this matters. A single physical device (say, a Medtronic Resolute Onyx drug-eluting stent) shows up under six different identifier systems depending on who's writing about it — CMS uses HCPCS/DRG, FDA uses product code + K-number, distributors use UDI-DI, the manufacturer uses brand names, and researchers use GMDN. This page unifies all of them under one device_category so you can pivot in any direction.
