Medicare Procedure Explorer

Every medical procedure, device, drug, and supply that Medicare pays for has a 5-character billing code (HCPCS). This tool lets you look up any code — like 33208 for a pacemaker — and see what it is, what Medicare pays, who provides it, and which hospitals are connected to it.

Try: 33208 (pacemaker) E0601 (CPAP machine) C9601 (drug-eluting stent) or type knee replacement

What you'll see for each code

What it is — official Medicare description, plus whether it's a device, drug, or service. What Medicare pays — hospital outpatient rates (for procedures), supplier rates (for equipment). Where it's used — top providers, top states, total volume. Hospital links — which hospitals' doctors bill this code most. Research — clinical trials studying related devices.
