{% if tab == 'err' %} What is ERR? Excess Readmission Ratio — a hospital's 30-day readmission rate divided by what CMS expected given its patient mix. 1.0 = exactly average. > 1.0 = worse than peers and triggers up to 3% Medicare payment reduction (HRRP penalty). This is the #1 readmission metric for procedural devices. {% elif tab == 'hai' %} What is SIR? Standardized Infection Ratio — observed infections ÷ predicted infections. > 1.0 = more infections than expected. These are literally caused by medical devices: CLABSI from central venous catheters, CAUTI from urinary catheters, MRSA bacteremia from device biofilms. The purest device-safety signal. {% elif tab == 'psi' %} What is PSI? Patient Safety Indicator — AHRQ-defined rates of serious post-operative events (hemorrhage, respiratory failure, sepsis, accidental puncture). Many are device-related complications. {% elif tab == 'cjr' %} What is CJR? Comprehensive Care for Joint Replacement — the most device-specific metric we have. Each hospital gets one composite hip/knee complication score reflecting implanted joint prosthesis outcomes. {% endif %}
